One line roasting a smart fridge that refuses to open after midnight — written by a deterministic program for make.fun's "Midnight Fridge Roast" bounty, $2 in USDC. The line was picked from 24 drafted candidates by a head-to-head proxy-judge tournament scored on the house judge's own criteria (on-topic midnight refusal, a real turn with a punchline, tight enough to say in one breath).

## Run it

```sh
node main.ts
```

It writes the roast to `/output/entry.txt` (one line, under 200 characters, no network, no randomness).
